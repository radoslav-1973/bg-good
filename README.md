# bg-good (good-bulgaria-for-people)

„Добра България за Хората“ е малък макет на платформа за политическа дискусия.

Проектът беше разработен единствено с изследователски цели:

-	Дали в България има почва за нов политически проект, който да не е обвързан с олигарси, сенчести групировки или 
  настоящи политически партии.  
-	Как хората възприемат развитието на атомната енергетика.
-	Как останалите политически партии в лицето на местните структури биха възприели евентуален конкурент.
-	Възможно ли е повече хора да участват в изборите.

Това наложи платформата да бъде възможно по-бърза, с ергономичен интерфейс, удобна и прозрачна за използване. 
Затова и кодът е написан от кота нула, единствено с помощта на HTML, CSS и Java Script.
